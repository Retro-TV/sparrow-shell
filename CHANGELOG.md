# Changelog

## 0.1.0 - 2026-09-19

- Public release under the Sparrow Shell name.
- Complete Hyprland and Ricelin-based Quickshell desktop configuration.
- Wallpaper-driven palettes shared across GTK, terminals, Firefox and Vesktop.
- Curated portable core and themed-app package manifests.
- Safe public `sparrow-update` and separate maintainer-only publishing flow.
- Portable monitor defaults, timestamped backups and clean-machine documentation.
- Screenshot gallery, demo recording, troubleshooting and upstream credits.
