# Keybindings

The authoritative bindings live in
`dotfiles/.config/hypr/modules/binds.lua`.

| Binding | Action |
| --- | --- |
| `Super + Return` / `Super + T` | Open Kitty |
| `Super + K` | Toggle the movable on-screen keyboard |
| `Super + F` | Open Firefox |
| `Super + E` | Open Thunar |
| `Super + Space` | Application launcher |
| `Super + V` | Clipboard history |
| `Super + C` | Wallpaper picker |
| `Super + B` | Shuffle wallpaper and regenerate colors |
| `Super + L` | Lock screen |
| `Super + D` | Screen recorder |
| `Super + G` | Game-mode surface |
| `Super + S` | Toggle stash workspace |
| `Super + P` | Toggle private workspace |
| `Super + 1..0` | Focus workspaces 1–10 |
| `Super + Shift + 1..0` | Move the active window to a workspace |
| `Super + Left/Right` | Previous/next workspace |
| `Super + left mouse` | Move a window |
| `Super + right mouse` | Resize a window |
| `Print` | rishot region/window capture |
| `Shift + Print` | rishot monitor capture |

Media, volume and brightness hardware keys are also mapped. Edit the Lua module
and reload Hyprland after changing bindings.
