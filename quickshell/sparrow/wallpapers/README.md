# Bundled wallpaper provenance

`default.png` is an original screenshot captured by the Sparrow author in
SpaceEngine Pro. The screenshot author distributes it as Sparrow's default
wallpaper and confirmed that the SpaceEngine/Steam terms permit screenshots
created in the software to be kept and distributed.

This records the asset's provenance and the author's confirmation; it does not
assert a separate third-party wallpaper license.
